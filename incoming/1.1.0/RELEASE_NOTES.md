# 1.1.0

- Проверка GitHub Releases вручную и автоматически при запуске и каждые 6 часов.
- Скачивание подписанных обновлений, установка отдельной версии и перезапуск.
- Резервная копия SQLite, проверка новой версии до разрешения действий и автоматическое восстановление при ошибке запуска.
- Возврат предыдущей версии при совместимой схеме базы.
- Публичные обновления из MSortGroups-Releases без аккаунта GitHub и без токенов.
- Дополнительная поддержка приватных релизов с доступом через Windows Credential Manager.
