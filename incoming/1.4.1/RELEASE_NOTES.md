# 1.4.1

- Одна ссылка группы проверяется один раз для каждого стабильного ID получателя при подготовке, включая отклонённые группы на других аккаунтах. Пропуски видны в логах.
- Подтверждённое участие запоминается между Trade; недавние подходящие группы повторно используются в пределах 15 минут при пересборке того же плана. Перед отправкой остаётся обязательная свежая проверка.
- Серый результат поиска без галочки сохраняется как кандидат, ожидающий подписок, без лишнего чтения полного состава. После подписок доступность выбора перепроверяется.
- Распознавание ошибок прокси при входе, поиске групп, чтении участников, профилей и Trade. Неисправный аккаунт получает статус «Ошибка прокси», без повторного перебора пароля/токенов и без потери сохранённых групп.
- Полный состав общей группы в обычном задании сбора используется повторно между аккаунтами, в том числе при параллельном сборе. Неполные результаты не блокируют другой источник.

# 1.4.0

- Два этапа Trade: проверка точного плана и отдельный запуск после передачи ссылок получателю.
- Свежая проверка стабильного ID, участия и доступности добавления в каждой выбранной группе, при любом фильтре качества.
- Готовое сообщение со ссылками только на фактически выбранные исходящие аккаунты и таблица конкретных групп.
- Проверка всех обратных подписок и всего плана до первого приглашения; без молчаливой замены групп или аккаунтов.
- Обновление непустых устаревших списков при подготовке, запрет самопроизвольного частичного обмена.
- Подтверждение конца контейнера чатов стабильными проверками; новый обмен блокируется при неполном начальном списке.
- Явное ручное подтверждение входящих для старых неполных снимков и сверка исходящих в закрытых Trade.
- Остановка ожидающего Trade сохраняет возможность продолжения; окончательное закрытие — отдельное действие.
- Ожидание кнопки добавления использует полный бюджет проверок вместо преждевременного ограничения группы.

# 1.2.1

- Trade ждёт подтверждённый выбор пользователя и готовность кнопки после перерисовки XChat.
- Обрабатывает дополнительное подтверждение после «Далее» и дожидается завершения формы перед переходом.
- Сверяет участие несколько раз при задержке ответа X, без повторной отправки приглашения.
- При неизвестном результате сохраняет браузер отправителя открытым и предлагает проверку результата; остановка сохраняет неподтверждённую попытку.
- Продолжение старого Trade сначала сверяет сохранённые попытки. Ошибки до отправки повторяются ограниченное число раз.
- Убраны лишние предварительные входы в исходящие аккаунты. Явно добавленный аккаунт обрабатывается первым даже без сохранённых групп.
- Ограничение добавления для пары группа–аккаунт перепроверяется после 15 минут; ошибки загрузки не выдаются за нехватку аккаунтов.
- В логах появились отдельные этапы выбора, отправки, подтверждения и сверки приглашения.
