# Murer Group Stats — публичные обновления

Готовые подписанные сборки: [открыть Releases](https://github.com/mur3r/MSortGroups-Releases/releases/latest).

Скачайте `MurerGroupStats-<версия>.zip` из вложений релиза, распакуйте в отдельную папку и запустите `install.cmd`, затем `start.cmd`. Нужен Python 3.11+ с launcher `py`; интерфейс уже собран, Node.js пользователю релиза не нужен.

В программе: **Настройки → Обновления программы → Проверить обновления → Скачать обновление → Установить и перезапустить**. Вход в GitHub и токены не требуются. Подробная инструкция находится в ZIP: `docs/UPDATES_GITHUB_RU.md`.

Здесь доступны файлы программы, включая Python-код. Данные пользователей, профили браузеров, пароли и закрытые ключи подписи в сборки не включены.

Каталог `incoming` используется автоматической публикацией; для установки выбирайте готовый ZIP из Releases. Изменения проходят тестирование и подписываются в рабочем репозитории владельца, затем этот репозиторий проверяет подпись и публикует все вложения одновременно.
